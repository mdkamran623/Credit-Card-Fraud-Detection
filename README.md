# 💳 Credit Card Fraud Detection System

A real-time fraud detection system with modern UI and multiple features.

## ✨ Features

- 🚀 Real-time transaction analysis
- 📊 Interactive fraud score visualization
- 📜 Transaction history with local storage
- 🌓 Dark/Light theme toggle
- 📋 Copy report to clipboard
- 🔊 Sound alerts for fraud detection
- 📥 Export history to CSV
- 📈 Statistics dashboard with charts
- 💾 Auto-save user preferences
- ⌨️ Keyboard shortcuts support

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python Flask
- **ML Logic:** Rule-based detection
- **Data Storage:** LocalStorage + SQLite
- **Charts:** Chart.js
